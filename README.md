Asistente de Recursos Educativos

Plataforma web desarrollada en Python con Flask para la gestión inteligente del aprendizaje, búsqueda optimizada de material pedagógico y recomendación algorítmica de contenidos.

### 🚀 Características principales
- **Motor de Búsqueda Integrado:** Consulta y filtrado dinámico de recursos educativos.
- **Servicios de Inteligencia Artificial:** Integración de modelos y procesamiento contextual.
- **Base de Conocimiento:** Activación de reglas de inferencia para generar rutas de estudio guiadas y personalizadas.
- **Arquitectura Modular:** Separación de componentes para motor de búsqueda, lógica de IA y pruebas unitarias (`test_app.py`).

### 🛠️ Tecnologías
- **Backend:** Python 3.10+, Flask
- **Frontend / Plantillas:** HTML/Jinja2 (Templates), CSS/JS (Static)
- **Control de dependencias:** pip (`requirements.txt`)
